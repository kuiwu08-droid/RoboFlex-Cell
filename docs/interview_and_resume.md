# 面试演示与简历表述

只有能自己解释并重现的内容才应写入个人经验。项目是可运行的SIL工程作品，不能以“完成博世产线/KUKA真机调试”描述。

## 5分钟演示

1. 30秒说明需求与边界：停带识别三类工件，流程控制+反馈闭环；展示需求矩阵、BOM和I/O。
2. 1分钟启动HMI：指出相机图像中的检测结果、像素/基坐标、抓取与放置状态。说明固定Z与平面标定条件。
3. 1分钟解释握手：Start→Running→撤Start→Complete→Ack→Ready。未确认完成时不能发下一任务。
4. 1分钟注入robot_timeout或持件急停：看出错工序与锁存报警，说明为什么保留夹持，如何解除原因、人工复位、重新启动。
5. 1分钟展示测试报告：100次合成循环与12种故障；区分模拟时间、墙钟时间、合成定位误差、真实设备误差。
6. 30秒说明下一步：导入厂家机器人模型和MoveIt，编译验证ST，再做低速空跑与实物定位误差测量。

## 据实可用的简历项目文字

**RoboFlex Cell｜视觉引导柔性分拣工作站（软件在环仿真）**

- 基于Python/OpenCV构建停带识别、平面坐标标定、机器人任务握手、夹爪和分类放置的自动化工作站仿真，提供本地HMI、I/O状态与生产日志。
- 设计顺序控制状态机、任务完成锁存、超时监控与人工复位机制，编写配套CODESYS Structured Text功能块源代码参考，并完成12种软件故障注入及恢复验证。
- 实现三类轮廓识别、像素到机器人基坐标和方向转换，以及工具包络路径避让；在100次合成循环中完成100次分拣，平均模拟周期6.33s。
- 输出工作站机械布局、SVG/DXF概念零件图、BOM、电气I/O方案和可复现测试报告，43项本地自动化测试通过。

如果简历空间有限，可压缩前两条与测试结果。不要把ST写成“已在CODESYS控制器运行”，也不要把SVG/DXF写成“SolidWorks完成制造装配图”。不要把合成图的0.05mm最大误差写成设备定位精度。

## 可以讲清楚的具体问题

- 图像v轴向下而机器人Y轴向上，角度必须一起变换；测试30°映射为150°。
- 直线路径会穿过夹具，高位预抓/预放避开工具包络碰撞；目标在夹具内部则拒绝。
- Complete必须锁存到确认后才清除；否则PLC可能因扫描相位错过短脉冲或重复启动。
- 安全门打开时松爪会带来掉落问题；仿真保留夹持，解除原因不自动重启。
- HMI按钮函数名与新HTML属性冲突，浏览器实测发现报错并修复；后端单元测试不能替代用户界面验证。

这些是本项目代码/测试可重现的情形。推荐稿中的“误差9.4→1.7mm”等示例不是你的测量，不应复制到简历。
