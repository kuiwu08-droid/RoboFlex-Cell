# 需求、验收与岗位对应

项目定位：固定相机、停带识别、三类平面工件的机器人柔性分拣 **软件在环（SIL）演示**。分拣到分类料盘，本版本没有压装/插装、力控或装配结果检测。

| ID | 需求 | 验证方式 | 对应职责 |
|---|---|---|---|
| R01 | 圆形、方形、带孔件识别 | 各 20 张带噪声合成图，类别与真值比较 | 机器视觉 |
| R02 | 工作平面像素 → 基坐标及局部方向变换 | 非仿射单应矩阵独立点验证，越界拒绝 | 坐标标定 |
| R03 | TCP 速度 ≤250 mm/s，夹具工具包络避让 | 直线路径被拒绝，高位路径每段碰撞检查 | 运动控制 |
| R04 | 来料→视觉→抓取→放置→质检→回家→统计 | 状态顺序与反馈验证 | 程序调试 |
| R05 | 启动/运行/完成/确认握手，无重复触发 | Complete 锁存、未确认禁止下一个任务 | 机器人集成 |
| R06 | 故障锁存，停输出，解除原因后人工复位 | 12 种注入故障、再运行验证 | 问题排查 |
| R07 | 已夹工件停止时保持，复位不自动重启 | 安全门故障时位置/夹持保持测试 | 设备验证 |
| R08 | 批量指标有原始记录 | seed=42，100 循环，JSON/CSV | 性能测试 |
| R09 | 机械布局、零件草图、BOM、电气 I/O | 原始 SVG/DXF/CSV 与设计说明审查 | 机械、电气方案 |
| R10 | ST 功能块设计 | 提供源代码、导入与联机测试步骤；待 CODESYS 验证 | PLC |

验收门槛：测试全通过；100 次正常仿真无报警；合成图定位最大误差 <0.5 mm；所有故障触发预期报警、停输送线和机器人、禁止直接启动、可以恢复一个正常循环。

不作为本版本验收：真实 KUKA 控制器、六轴逆运动学/关节碰撞、ROS2/MoveIt/Gazebo、实际 CODESYS Runtime、SolidWorks 原生模型、相机内参/3D 手眼标定、实体设备安全认证。这些需要额外环境或硬件，不写成已有经验。
